# SolarWinds

SolarWinds is a company that provides IT management and monitoring software to help organizations manage their on-premises, hybrid, and cloud-based IT environments. Its products cover a wide range of needs, including network performance, system management, database monitoring, and IT automation. The software offers features like customizable dashboards, traffic analysis, and cloud visibility across platforms like AWS, Azure, and Google Cloud. 

We use SolarWinds primarily for observability to monitor the health of our infrastructure and automatically create tickets when an incident occurs.

## Our Instance

In order to access our SolarWinds instance you will need to submit a Standard SNOW ticket requesting to be added to the `Solarwinds Read Only Users` group.

You can access our SolarWinds instance [HERE](https://numswp21.na.imtn.com/Orion/Login.aspx?ReturnUrl=%2fOrion%2fSummaryView.aspx%3fViewID%3d1&ViewID=1).
