# Active Directory

There are two main things that we are responsible for when it comes to managing user accounts within Active Directory; Group Assignment/Removal and account password resets. How this is done differs from which Network the account is part of; Corporate/FISMA or GovCentral. We've been given access to both of the Active Directory setups so that we can handle and assist with these tasks.

## Group Assignment/Removal

When a user joins Iron Mountain their Windows/Network account is created within Active Directory and most of their access and permissions are then granted through group membership. The main instance in which we have to perform a task for this is when there is a new member of the Operations Team who is going to be scanning documents with an IBML scanner, working within Kofax, etc. and their account needs to be added to a site specific AD Group. Some sites will have multiple Groups, depending on which projects they're operating, IE: IRS, GDIT, DLA, VHA, etc.


## Account Issues

There are two main account issues that we can assist with; password resets and account lockouts.

Users across all Teams will forget their passwords. We all do. Sometimes they expire before we're able to change them too. Accounts will get locked after so many failed login attempts and they will need to be unlocked. Sometimes these two things coincide with one another.
