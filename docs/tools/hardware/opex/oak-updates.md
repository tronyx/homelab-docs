# OAK Updates

## CertainScan Monitor OAK

1. Remote into Transform Server.
![Opex-OAK-1](../../../overrides/assets/images/opex-oak-1.png#center)
2. Open OPEX Monitor and sign in as tech for OPEX. OPEX should provide the password.
![Opex-OAK-2](../../../overrides/assets/images/opex-oak-2.png#center)![Opex-OAK-3](../../../overrides/assets/images/opex-oak-3.png#center)
3. Proceed to `“System Setup”` on the top and then select `“Software Options”`. That will open UMI information for CertainScan Monitor.
![Opex-OAK-4](../../../overrides/assets/images/opex-oak-4.png#center)
4. Select `“Next”`.
![Opex-OAK-5](../../../overrides/assets/images/opex-oak-5.png#center)
5. Change `“Expire on”` date to date provided by Opex and then click `"Next"`.
![Opex-OAK-6](../../../overrides/assets/images/opex-oak-6.png#center)
6. Enter in New Key then click `"Next"`.
![Opex-OAK-7](../../../overrides/assets/images/opex-oak-7.png#center)
7. Make sure OAK is accepted. Click finish and then it will ask to restart software.
![Opex-OAK-8](../../../overrides/assets/images/opex-oak-8.png#center)


## CertainSan Transformation OAK

1. On the left side select `"Transform"`. Then, in the middle of the screen, select `“Launch CertainScan Transform Configuration"`.
![Opex-OAK-9](../../../overrides/assets/images/opex-oak-9.png#center)![Opex-OAK-11](../../../overrides/assets/images/opex-oak-11.png#center)
2. Click `“System Configuration”` on the top left and then select `“Licensing”` from the drop-down menu.
![Opex-OAK-10](../../../overrides/assets/images/opex-oak-10.png#center)
3. Click `“Next”`.
![Opex-OAK-11](../../../overrides/assets/images/opex-oak-11.png#center)
4. Change `“Expire on”` date to date provided by Opex and then click `"Next"`.
![Opex-OAK-12](../../../overrides/assets/images/opex-oak-12.png#center)
5. Make sure OAK is accepted. Click finish and then it will ask to restart software. After restart get back into Opex software and confirm everything is working correctly.
![Opex-OAK-13](../../../overrides/assets/images/opex-oak-13.png#center)
