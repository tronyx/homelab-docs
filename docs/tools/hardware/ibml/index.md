# IBML

![IBML](../../../overrides/assets/images/ibml.jpg#center)

The IBML ImageTrac-Lite is a high-speed document scanner that is designed for businesses that need to scan a large volume of documents quickly and easily. It can scan up to 60 pages per minute, and it can handle a variety of document types, including letter-sized documents, legal-sized documents, and envelopes.


## Features

The ImageTrac-Lite also features a number of advanced features that make it easy to use and manage, such as:

- A built-in auto-feeder that can automatically feed documents into the scanner.
- A document separation sensor that can detect and separate double-feeds.
- A batch scanning mode that allows you to scan multiple documents at once.
- A built-in software suite that provides a variety of features for managing and processing scanned documents.


## Applications

The IBML ImageTrac-Lite is a versatile and powerful document scanner that can be used for a variety of applications, such as:

- Mailroom processing.
- Document digitization.
- Compliance archiving.
- Legal discovery.
- Medical records management.

If you are looking for a high-speed, reliable, and easy-to-use document scanner for your business, the IBML ImageTrac-Lite is a great option.


## Additional Details

Here are some additional details about the IBML ImageTrac-Lite:

- It has a resolution of up to 600 dpi.
- It can scan both color and black-and-white documents.
- It supports a variety of output formats, including PDF, TIFF, and JPEG.
