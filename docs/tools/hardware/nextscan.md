The STimaging ViewScan 4 and PerfectView software are a powerful combination that can help businesses and organizations digitize their microfilm archives quickly and easily.

## Scanner

The STimaging ViewScan 4 is a high-resolution microfilm scanner that is designed for businesses and organizations that need to digitize microfilm archives. It has a 18MP camera that can scan microfilm at up to 30 frames per second, and it can output images in a variety of formats, including PDF, TIFF, and JPEG. The ViewScan 4 also features a number of advanced features that make it easy to use and manage, such as:

- A built-in auto-feeder that can automatically feed microfilm into the scanner.
- A PerfectFocus technology that delivers crisp and clear images instantly at all times, even when browsing.
- A zoom function that allows you to magnify images for closer inspection.
- A built-in software suite that provides a variety of features for managing and processing scanned microfilm.


## Software

The PerfectView software is a powerful tool that is designed to work with the ViewScan 4 microfilm scanner. It allows users to browse, crop, save, and share scanned images in a variety of ways. The software also includes a number of advanced features, such as:

- A search function that allows you to quickly find specific images.
- A batch scanning mode that allows you to scan multiple images at once.
- A watermarking feature that allows you to add a watermark to scanned images.
- A export function that allows you to export scanned images to a variety of file formats.
