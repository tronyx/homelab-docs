# Kofax Tools

## Batch Manager

The primary application for working with Kofax.


## KC Batch Removal Utility

This tool is specifically used to remove a Batch from Kofax. Normally it is used if a Batch is stuck in a process and Operations just need it gone. The other side of the tool is that you can backup before removal or even backup and leave the original Batch, then import it using the Kofax import application.


## Administration

The administration utility for Kofax.


## Remote Synchronization Agent

The RSA keeps a Remote Site in sync with the Kofax Central Server and is a good tool to ensure connectivity is functioning as expected between the Central Server and a Remote Site.
